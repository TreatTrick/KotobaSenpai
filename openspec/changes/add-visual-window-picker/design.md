## Context

识别页目前通过 `RecognitionPage.xaml` 中的 `ComboBox` 和刷新按钮选择窗口。`RecognitionPageViewModel.Refresh()` 枚举窗口并默认选择第一项，`MainWindow.InitializeViewModel()` 在启动时执行刷新，因此用户尚未操作就可能已有目标。

现有基础可以复用：

- `WindowTarget.Bounds` 表示客户区屏幕物理像素矩形，不包括标题栏和边框。
- `IWindowFrameCapture` / `WgcWindowFrameCapture` 提供目标自身的 BGRA 帧，首帧等待有界，支持取消、遮挡和会话停止。
- `ITargetWindowTracker` 提供客户区、DPI、有效性和最小化状态；切换目标会终止旧识别并切换跟踪。
- `OverlayWindowRegistry` 已登记辅助 HWND，正常词线、释义和区域选择窗口继续遵守目标 owner 和非全局置顶规则。
- 主程序是启用 PerMonitorV2 的 WPF 应用；本次使用已有框架和 Win32 / DWM 能力，不增加依赖。

用户已确认缩略图采用选中时的一张静态截图。本变更只规划选窗交互，与正在进行的标注配色变更分别交付。

## Goals / Non-Goals

**Goals:**

- 通过按钮进入桌面拾取，悬停窗口显示真正沿周长流动的彩虹边框，单击选中，Esc 取消。
- 确认后保留彩虹边框作为待识别提示，点击开始识别时移除。
- 用截图飞入和正方形静态预览确认目标，移除旧列表、刷新及启动自动选择。
- 保持目标绑定与 OCR / LLM 调用分离，处理取消、重复操作、捕获失败和目标失效。
- 在多显示器、负坐标和混合 DPI 下保持边框、截图来源和动画终点一致，及时释放临时资源。

**Non-Goals:**

- 实时窗口直播、定时更新缩略图、截图历史、缩略图持久化或上传。
- 鼠标拖拽准星、窗口列表备用入口、浏览器标签页选择或桌面区域选择。
- 用桌面截图、GDI 或 PrintWindow 回退替代 WGC，承诺读取受保护内容或支持独占全屏。
- 改变 OCR 选区、自动识别策略、正常标注窗口的 Z 顺序，或新增彩虹配色设置。

## Decisions

### 1. 将桌面拾取作为窄端口，呈现留在 App / Windows 层

在 Core 的 `TargetWindow` slice 增加 `IWindowPicker`，提供可取消的异步选择并返回 `WindowTarget?`。无结果代表用户取消；真正的输入 hook 或原生调用失败使用稳定错误码及异常表示。端口不暴露 WPF 类型、位图或桌面动画对象。

端口同时提供 `Highlight(WindowTarget?)`：非空值跟随已选窗口显示被动彩虹边框，空值立即关闭并释放。复用同一 Windows 边框组件，不引入新的呈现端口。ViewModel 记录本次选择是否仍在等待首次识别，在识别调用前清除提示；结束或失败的识别不自动恢复提示，重新选择（包括同一窗口）重新进入待识别状态。

暂不可用不清空边框绑定，由 Windows 跟随器隐藏并保留原 PID / TID。若跟随器检测身份丢失而关闭，其已退休的绑定仍保留到显式重置；后续同 HWND 通知不允许重新绑定到替代窗口。

职责划分：

| 层 | 职责 |
| --- | --- |
| Core / TargetWindow | 选窗端口及现有目标、帧、跟踪契约 |
| Platform.Windows | 候选命中、窗口身份复核、临时输入 hook、彩虹边框和 Esc 提示 |
| App ViewModel | 选择命令、操作代次、确认后切换会话、预览请求和错误状态 |
| App WPF 呈现组件 | 主窗口隐藏 / 恢复、帧转位图、正方形预览、桌面飞入动画及位图释放 |

预览仍使用现有 `IWindowFrameCapture`，不增加第二套截图实现。ViewModel 保持可无界面测试；局部呈现组件接收带选择代次的结果，消费后不长期保存原始全尺寸帧。不引入通用消息总线或新的工作流框架。

比较过系统窗口选择器：它不能提供指定的悬停彩虹和点击行为。扩展现有枚举列表也仍需用户辨认标题，因此采用自定义拾取。识别页移除 `IWindowCatalog` / `Win32WindowCatalog` 的依赖和 DI 注册。现有 `tools/WgcCaptureProbe` 仍合法使用枚举能力，因此保留这两个类型，不为删除它们而改写无关工具。

### 2. 拾取与提交分开，取消不破坏原目标

状态分为两条轴：目标状态为未选择 / 有效 / 暂不可用 / 已关闭，操作状态为 Idle / Picking / AcquiringPreview / Animating。所有异步结果携带递增的选择代次。

```text
Idle（可已有目标与缩略图）
  └─ 选择窗口 → Picking（保存主窗口状态并临时隐藏）
       ├─ Esc / 拾取失败 → 恢复主窗口 → Idle，保留原目标与图片
       └─ 有效左键点击 → 恢复主窗口、复核并提交目标 → AcquiringPreview
            ├─ 成功 → Animating → Idle，显示静态缩略图
            └─ 预览失败 → 恢复主窗口 → Idle，显示新目标和重试入口
```

Picking 只维护内部候选，不修改 `SelectedWindow`，不对 hover 候选调用 tracker.Attach、WGC、OCR 或 LLM。已有识别会话按原规则继续；取消拾取不会主动结束该会话。因真实窗口关闭或最小化产生的原有生命周期事件照常生效，不为了取消而恢复已失效目标。

确认点击完成并再次校验目标后才结束旧识别、取消在途工作、清除旧预览、提交新目标并 Attach 跟踪。即使重新拾取同一 HWND，也将其视为一次明确的新选择：刷新静态截图并回到待识别状态，不能依赖属性值是否发生变化来终止旧会话。

Picking 和 AcquiringPreview 期间禁止重入选择、识别与区域编辑命令。Animating 只影响呈现；新的选择、页面离开、隐藏或窗口关闭取消旧动画，不回滚已经提交的目标。代次检查阻止旧帧、旧错误和旧动画完成回调覆盖新选择。

### 3. 按实际顶层窗口命中，区分外框与客户区

在当前桌面定位鼠标下可选择的顶层窗口，子控件解析到其 root window；owned dialog 保持为实际可见的顶层对话框，不自动替换成 owner。

排除本应用进程的窗口、拾取辅助 HWND、桌面、任务栏、不可见、cloaked、最小化、已销毁或客户区为空的窗口。无标题但其他条件有效的窗口可以选择，UI 使用本地化的未命名提示。只跳过本应用辅助表面；其他应用的普通遮挡窗口仍参与命中，不能隔着前面的窗口选择后面的窗口。

原生命中与 Z 顺序检查共用同一套候选规则，避免边框出现后反过来命中边框。候选内部记录 HWND 与进程 / 线程身份，在鼠标按下、释放及返回结果前复核，防止 hover 后窗口销毁并复用句柄。确认时重新读取客户区边界。

彩虹边框使用 DWM 可见外框矩形，包含标题栏；`WindowTarget.Bounds` 和截图继续使用客户区，保持现有 OCR 坐标契约。飞入起点使用取得有效帧时对应的客户区矩形，不能把包含标题栏的外框直接套到客户区图片上。

### 4. 输入 hook 只在拾取期间存在，完整消费确认点击

采用临时低级鼠标 hook 和 Esc 键 hook，在有消息循环的专用输入线程中工作。回调只记录输入、同步决定是否消费、排队 UI 通知；不执行 WPF 绘制、截图等待或 OCR。Win32 查询和回调异常必须在边界内捕获。

选择在一组完整的左键按下 / 释放后提交。按下时锁定候选，释放时复核仍为同一有效窗口；发生拖动到其他候选或目标失效时，不提交并继续拾取。Picking 期间无效位置的左键点击也成对消费，避免操作桌面或其他窗口。Esc 作为取消手势消费，不让取消按键同时触发目标软件。

正常确认在消费释放后拆除 hook；Esc 按下时即进入取消状态，在 Esc 和已经接住的左键都释放后完成正常取消，避免交错输入的释放事件泄漏。其他取消、错误和应用退出执行统一清理。原生安装失败时撤销已安装部分，恢复主窗口并显示可重试提示。输入服务不能在选择完成后继续拦截任何后续点击，也不合成点击或 Esc 发送给目标。

### 5. 彩虹沿边框周长流动，选中后保留到开始识别

使用透明、不可激活、无任务栏项、原生点击穿透的 WPF 边框窗口。拾取及待识别提示层允许临时全局置顶，原有识别浮层继续按目标 owner / Z 顺序运行。辅助 HWND 创建后登记，关闭时注销，避免影响现有遮挡计算；不改变 tracker 按明确辅助 HWND 排除遮挡的规则。

边框约 3 DIP，带轻微辉光和圆角。沿圆角矩形周长分段绘制连续彩虹色，通过推进颜色相位形成流动；不旋转整个窗口、矩形或图像。使用已有 WPF 绘制能力，避免为单个效果引入 shader 或动画库。悬停目标切换后更新边界并继续流动；同一候选移动 / 缩放时刷新几何。确认后关闭拾取提示及输入 hook，复用边框组件，以 UI 计时器继续跟随已选窗口的可见外框和 DPI；此阶段不拦截输入，也不保持 WGC 预览采样。开始识别前关闭边框和计时器。

鼠标所在显示器同时显示简短的点击 / Esc 提示，不遮住命中位置；确认后提示消失，彩虹边框继续保留到用户开始识别，与预览获取或飞入是否成功无关。无候选时隐藏拾取边框但保留取消能力。重新拾取期间暂停原待识别边框，取消或拾取失败时恢复仍有效的原待识别边框；已有识别会话不恢复该提示。目标隐藏 / 最小化时暂时隐藏，恢复后继续显示；目标关闭、换目标或应用退出时释放，并复核进程 / 线程身份防止 HWND 复用。遵循系统减少动画设置：关闭连续流动和飞行动画，保留静态彩虹边框与最终选中反馈。

### 6. 一次预览捕获，保留缩略图并立即结束预览会话

确认新目标并结束旧会话后调用 `IWindowFrameCapture.CaptureAsync`，不传 OCR 选区，获取完整客户区的一帧；复用现有 2 秒首帧上限、取消和几何复核。失败不回退成屏幕同位置截图，不将全黑图像自行判定为受保护内容。

App 使用同一有效帧建立飞行图片与最终缩略图。飞行图片只在动画期间保留，最终静态位图按预览尺寸及当前 DPI 缩小；不长期保留全尺寸 `CapturedFrame` 或 GPU 资源。只为预览启动的 WGC 会话在本次请求成功、失败或取消后 Stop，清理完成的所有权交接发生在重新允许识别前，避免旧请求的 finally 停止新识别会话。

预览失败不撤销已成功提交的窗口：卡片显示新标题、“预览获取失败”和重试入口，旧目标图片已清除。显式重试仅重新获取当前目标的预览，不启动 OCR、不播放从桌面飞入的选窗动画。窗口最小化 / 隐藏时保留原静态图并标记暂不可用，恢复后只恢复资格，不自动刷新图片。窗口销毁时清除有效目标与图片，标记已关闭并提供重新选择。

预览重试只在没有在途识别或活动识别会话时可用。若用户在预览失败后已经开始识别，先通过现有结束识别入口结束会话，或重新选择窗口；不让预览重试复用并 Stop 运行中识别的捕获会话。

识别开始、自动识别采样、画面变化、窗口移动 / 缩放、切换主题和切换标签页都不更新静态图。图片不写文件、不上传，也不进入既有识别诊断截图输出链。换目标、目标关闭和应用退出时释放对应图像。

比较过 DWM 实时缩略图和持续 WGC 采样：前者是持续连接的实时呈现，后者需要长期捕获资源，均不符合已确认的静态反馈，因此本次只进行一次捕获。

### 7. 飞入使用桌面呈现层，目的地由页面实际布局给出

App 在隐藏前保存主窗口正常 / 最大化状态，隐藏自身不会改变其位置。拾取确认或取消后立即恢复主窗口，避免用户在首帧等待期间看不到应用；失败与异常路径也恢复可见状态。不为截图激活、恢复或置顶目标窗口。

主窗口恢复时请求激活；截图成功后等待目标卡片布局有效，必要时将卡片滚动到可见位置，再读取预览框内部图片的屏幕矩形。透明、不可激活、原生点击穿透的临时桌面窗口承载飞行图片，从捕获时客户区位置沿轻微弧线缩小到目标矩形，约 400 毫秒完成。图片按原比例缩放，落入时做轻微回弹并交给静态预览显示。真实目标窗口不移动、不缩放。

桌面动画必须跨出主窗口边界，因此不用页面内 `Adorner` 单独承担整条路径。多屏场景以屏幕物理像素为几何基准，使用一张覆盖虚拟桌面的短生命周期表面，并按该表面的实际 PointFromScreen / PointToScreen 变换统一转换为 DIP，保留负坐标。彩虹描边额外按目标窗口 DPI 调整粗细；图片本身以物理矩形插值，避免跨显示器切换呈现表面产生接缝。只有实际桌面尺寸超过渲染纹理限制时再拆分表面。预览框终点在最后一次布局后重新计算。

如果主窗口未能激活、目标卡片不可见、显示器布局变化、页面离开、系统禁用动画或呈现失败，立即展示最终静态缩略图并结束临时动画。动画失败不使选择失败。临时桌面窗口和计时 / 渲染订阅都必须注销和释放。

### 8. 目标卡片展示与现有 Fluent 界面一致

目标卡片增加约 144 × 144 DIP 的正方形预览区域，右侧为窗口标题、状态和选择按钮；空间不足时纵向排列。图片使用等比例完整适配，留白使用主题画刷，不拉伸、不居中裁掉画面。144 DIP 为初始设计值，可在保持正方形和现有布局约束的前提下微调。

未选择显示窗口图标与选择提示；已选择显示静态图、标题和“重新选择窗口”。长标题截断并可查看完整内容。预览错误、暂不可用和已关闭提示位于所属卡片内。其他识别、区域设置和自动识别卡片保留现有分组。

新增中文和英文 `.resx` 文案，选择按钮支持键盘操作，卡片提供窗口标题与状态的可访问名称，状态变化使用现有无障碍通知模式。代码、注释、测试方法 / 断言和日志使用英文。拾取彩虹颜色固定，不从标注外观配置读取。

## Risks / Trade-offs

- 输入 hook 未成对释放导致一次点击泄漏或残留拦截 → 原生状态机先消费释放再正常退出，异常统一清理；用真实桌面按钮 / 游戏场景人工验收，单元测试覆盖按下、释放、失效和取消序列。
- 临时辅助窗口干扰命中、焦点或遮挡计算 → 使用原生不可激活 / 点击穿透样式，登记准确 HWND；候选命中与业务遮挡分别应用各自排除规则。
- WGC 与新识别共享捕获服务，旧 Stop 影响新请求 → 串行化预览获取和清理，之后才开放识别；所有结果均校验选择代次。
- 选择取消时原目标恰好关闭 → 由 tracker 的真实状态覆盖旧选择，不复活已失效句柄或图片。
- 混合 DPI 可能使彩虹框偏移或飞行图片跳变 → 外框、客户区、图片内容框分别记录；覆盖 100% / 125% / 150%、负坐标和跨屏场景。
- 操作系统可能拒绝激活，受保护应用或独占全屏可能无法呈现 / 捕获 → 保留可操作失败提示；允许跳过动画，不改变捕获后端或自动提权。
- 动效可能影响性能或舒适度 → 彩虹绘制仅在拾取和待识别阶段运行，跟随系统减少动画设置；开始识别、目标关闭或退出后不留边框计时器，飞行结束后不留全尺寸图片。

## Migration Plan

1. 增加选窗端口、Windows 拾取实现和可测试的输入 / 候选逻辑，保持业务层依赖方向。
2. 集成选择命令、确认提交、一次预览与 App 呈现，替换卡片并删除启动刷新。
3. 移除旧列表专用状态、资源键、测试和无调用者的枚举端口 / 适配器，更新依赖注入。
4. 执行状态机、捕获生命周期、视图 / 本地化和架构检查，以及 Windows 多屏人工验收。

没有设置或持久化数据迁移。若整体回退，回退本变更即可恢复旧列表；不影响独立的标注配色变更。

## Open Questions

没有阻塞实现的产品决策。静态缩略图已确认；约 144 DIP 的预览尺寸和约 400 毫秒的飞入时长为可在验收中微调的初始值。

实现前需在实际 Windows 桌面验证低级输入 hook 的成对消费、主窗口恢复激活及跨 DPI 呈现接续；这是验证任务，不扩展为新功能。

## Why

当前通过窗口标题下拉列表选择目标，用户需要在多个相似名称之间辨认，选中后也没有画面确认。改为直接在桌面拾取窗口，并用截图飞入和静态缩略图反馈，让用户明确知道选择了哪个窗口。

## What Changes

- 用“选择窗口 / 重新选择窗口”按钮替换目标窗口下拉列表和刷新按钮，启动时保持未选择状态。
- 点击按钮后暂时收起主窗口，鼠标悬停的有效顶层窗口显示沿外轮廓流动的彩虹边框；单击确认，Esc 取消并恢复原选择。
- 确认后彩虹边框继续跟随已选目标，直到用户开始识别；最小化 / 隐藏时暂时隐藏，恢复后继续显示，目标关闭或应用退出时清理。
- 选择器接住确认点击的按下和释放，避免同时操作目标软件；排除本应用窗口、辅助浮层、桌面和任务栏。
- 确认后恢复主窗口并获取目标客户区的一帧截图，将同一张截图的副本从目标位置缩小并飞入识别页的正方形预览框。
- 预览框按原比例完整显示静态缩略图，展示窗口标题和选择状态；只有重新选择目标或显式重试失败的预览时才获取新图。
- 选窗只绑定目标和获取预览，识别仍由“开始识别”触发。补齐取消、捕获失败、目标关闭、多显示器和不同 DPI 的行为。
- 缩略图和动画图像仅在内存中使用；预览获取完成后释放专用于本次预览的捕获资源。

## Capabilities

### New Capabilities

- `visual-window-picker`：桌面鼠标拾取、动态彩虹边框、点击确认与取消、截图飞入、静态缩略图及其生命周期。

### Modified Capabilities

- `window-word-overlay`：将窗口选择要求从可见窗口列表改为显式桌面拾取，保持选窗与识别分离，并允许当前选择的内存缩略图。
- `fluent-ui`：将目标窗口卡片从标签加下拉控件改为正方形预览、窗口信息和选择按钮，保留其他卡片与主题行为。

## Impact

- Core / TargetWindow：增加不依赖 WPF 的异步选窗端口，复用 `WindowTarget`、`CapturedFrame`、`IWindowFrameCapture` 和目标跟踪端口。
- Platform.Windows：实现鼠标拾取、输入拦截、候选窗口校验和彩虹边框；复用现有 WGC 捕获与辅助窗口登记机制。
- App：更新识别页、ViewModel、主窗口收起与恢复、截图飞入呈现和依赖注入；移除仅服务于旧列表的刷新、启动自动选择及无调用者的枚举代码。
- Localization：增加中英文选择提示、预览状态和错误文案；代码、注释、测试及诊断信息继续使用英文。
- Tests：覆盖选择状态、取消和晚到结果、输入清理、窗口筛选、静态预览与捕获生命周期；通过 Windows 桌面验收确认动画、焦点和混合 DPI。
- 不新增第三方依赖，不改变 OCR、LLM、识别区域或普通识别覆盖层的 owner / Z 顺序规则。本变更与 `customize-overlay-colors-and-outlines` 独立，拾取边框不使用标注颜色设置。

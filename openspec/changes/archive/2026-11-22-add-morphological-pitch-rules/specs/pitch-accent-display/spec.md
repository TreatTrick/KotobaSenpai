## ADDED Requirements

### Requirement: 基于 UniDic 结合与变形字段计算形态学整词音调
对于未发生读音覆盖（`HasOverriddenReading == false`）且在人工校正表、离线词典和白名单助数词规则均未命中的词块，系统 SHALL 使用 `SourceTokens` 的 UniDic `AType`、`AModType` 与 `AConType` 在本地离线计算整词音调核（来源标记为 `SpanPitchSource.MorphologicalRule`）：
- 单 token 词块仅在携带可解析的 `AModType`（`M1@k`、`M2@k`、`M4@k`）且具备有效基础音调核时应用变形计算；无 `AModType` 的普通单 token SHALL 返回未知（沿用既有单 token `aType` 展示）。
- 多 token 词块 SHALL 从左至右逐语素递推计算：按 `AModType`（含 `M4@k` 对无声化母音不前移与特殊拍 `っ`/`ん`/`ー` 继续左移一拍的保护）处理活用变形，按 `AConType` 处理付属語（`F1`–`F6`，含 `助動詞-タ` 单拍末拍平板归一避免产生动词尾高型）、接尾辞/複合語（`C1`–`C5`）与确定性接頭辞（`P1`/`P2`/`P6`/`P13`/`P14`）的结合变调，并允许活用助动词多层连续叠链。
- 当词块发生读音覆盖、任意必需 token 缺少有效读音/基础音调/匹配规则，或遇到未支持的规则标记或越界结果时，系统 MUST 失败关闭并返回未知，交由既有回退路径处理，不得伪造音调。

## MODIFIED Requirements

### Requirement: 整词优先的分层离线音调解析
系统 SHALL 在确定每个词块的最终有效读音后（包括首次本地分组以及 LLM 返回经校验的语境读音纠偏之后），按以下优先级在本地离线解析该词块的整词音调（`SpanPitch`）：
1. 项目人工校正表，优先按 `(原始表记, 平假名有效读音)` 精确匹配，未命中时再尝试适用的汉数字规范化表记；
2. 离线 Kanjium SQLite 词典（`pitch-accent.db`），按 `(表记, 平假名有效读音)` 精确匹配（含对阿拉伯数字表记的汉数字规范化查表）；
3. 高确定性白名单助数词规则（`週間`、`時間`、`年生`、`ヶ月` 变体、`曜日`）；
4. 基于 UniDic `AType`/`AModType`/`AConType` 的形态学音调结合规则（仅在未发生读音覆盖时适用）。

整词词典查询 MUST 仅使用词块的出现形 `Surface` 与最终有效读音，不得将 `LookupKey` 辞书形的词典音调直接套用到活用出现形（例如不得将 `食べる[2]` 套用到 `食べて`）；活用出现形应由第 4 层形态学规则按 UniDic 结合与变形字段推导出实际音调（如 `食べて` → `[1]`）。整词解析命中的全部合法候选核位置 SHALL 按来源顺序保留在 `SpanPitch.Positions` 中，并以第一个候选作为主展示位置；解析结果 SHALL 仅用于本地展示与诊断，不得加入 LLM 请求体。

#### Scenario: 一週間经离线词典解析出整词音调
- **WHEN** `一週間`（或 `1週間`）经有效读音解析确定为 `いっしゅうかん`
- **THEN** 分层解析通过 Kanjium 精确命中整词 `SpanPitch`，位置为 `[3]`，来源为 `Dictionary`

#### Scenario: 三週間经白名单助数词规则解析出整词音调
- **WHEN** `三週間` 经词块分组确定有效读音为 `さんしゅうかん`，且人工校正表与离线词典均无整词记录
- **THEN** 分层解析回退至白名单助数词规则，产出整词 `SpanPitch`，位置为 `[3]`，来源为 `CounterRule`

#### Scenario: LLM 纠偏读音后重新解析整词音调
- **WHEN** `額` 的有效读音被 LLM 从 `がく` 纠偏为 `ひたい`，且离线词典收录 `額（ひたい）` 的整词音调
- **THEN** 系统以 `("額", "ひたい")` 重新运行分层解析并更新为新读音对应的整词 `SpanPitch`，不再停留在音调未知或仅单 token 参考

#### Scenario: 活用形不误用辞书形词典音调而由形态学规则解析
- **WHEN** 词块 `Surface` 为 `食べて`、`LookupKey` 为 `食べる`、有效读音为 `たべて`，离线词典仅收录 `食べる` 而未收录 `食べて`
- **THEN** 整词词典查询不以 `食べる` 查表，第 4 层形态学规则基于 `食べ(aType=2, aModType=M4@1)` 与 `て(aConType=動詞%F1)` 产出 `SpanPitch([1], MorphologicalRule)`；当形态学字段缺失时安全回退为空

# KotobaSenpai website

An animated, bilingual product website built with Svelte 5, SvelteKit 3, TypeScript, Vite 8, pnpm, and GSAP. English and Simplified Chinese pages are prerendered for GitHub Pages.

## Develop

Use Node.js 24 and pnpm 10.14.0:

```sh
cd website
pnpm install --frozen-lockfile
pnpm dev
```

Open `/KotobaSenpai/` or `/KotobaSenpai/zh/` on the printed local server URL.

```sh
pnpm test
pnpm check
pnpm build
pnpm preview
```

Static output is generated in `build/`. `.github/workflows/website.yml` verifies and deploys this directory on relevant pushes to `main`. The Pages source is GitHub Actions. Desktop release tags stay on their release commits.

Download buttons use GitHub's `/releases/latest/download/KotobaSenpai-win-x64-Setup.exe` URL, and release notes use `/releases/latest`. Publish the `KotobaSenpai-win-x64-Setup.exe` alias generated by `scripts/Build-Installer.ps1` alongside the versioned installer in every stable release. Both files contain the same installer bytes. New releases then update the website's download target without rebuilding or redeploying the website.

## Content and media

- `src/lib/content.ts`: English and Chinese copy, screenshots, installer and repository links.
- `src/lib/Landing.svelte`: product narrative, language gallery, chapter selection, onboarding, FAQ, and scroll motion.
- `src/lib/DemoPlayer.svelte`: visible-only playback with pause controls and motion preferences.
- `src/app.css`: responsive styling and OKLCH design tokens.
- `static/media/`: optimized derivatives of the existing `../docs/assets` GIFs and screenshots. Original game demonstrations are retained in the repository.

The Chinese homepage's hero video link opens the introduction on Bilibili in a new tab. Its URL is defined by `INTRODUCTION_VIDEO_URL` in `src/lib/content.ts`. The English homepage keeps its on-page experience link.

To regenerate optimized media after updating the originals, install `Pillow==13.0.0` and `imageio-ffmpeg==0.8.1` in a Python environment and run `python scripts/prepare-media.py`. Ordinary pnpm builds need neither Python nor FFmpeg.

## Dragon maid

The transparent atlases and playback behavior are reused from `D:/project/Clutch/website`: `mood.webp`, `jump.webp`, `happy.webp`, `mascotFrames.ts`, `mascotPlayback.ts`, and `Mascot.svelte`.

She wags her tail when happy, becomes sad as the pointer moves up through the page's top zone, and loops the original jumping clip when a download link is clicked. Drag horizontally or use the arrow keys, Home, and End. Her normalized position is stored locally under a KotobaSenpai-specific key. Animation pauses in hidden tabs and when motion is disabled. Reduced-motion visitors see still poses. The browser cannot detect a tab-close button; the interaction approximates exit intent.

No analytics, account system, credential collection, or backend is included.

## Search discovery

The Google Search Console URL-prefix property is `https://treattrick.github.io/KotobaSenpai/`.
Keep the `google-site-verification` meta tag in `src/app.html` after verification; Google periodically checks ownership again.
The public verification value is not an API credential and must be present in the deployed HTML.

The sitemap is `https://treattrick.github.io/KotobaSenpai/sitemap.xml` and lists both prerendered language pages.
Each page has a descriptive title, description, canonical URL, and reciprocal language alternates.
GitHub project Pages serves `robots.txt` under the project path; crawler rules are read from the host-root `/robots.txt`, not this project file.
Search Console submission requests discovery and crawling; Google decides whether and when to index each page and how to rank it.
